# Programación en Finanzas

Repositorio de apoyo para el curso **Programación en Finanzas**.

El objetivo del curso es que los estudiantes aprendan a usar herramientas de programación para resolver problemas financieros, automatizar cálculos, analizar datos y construir una base técnica sólida para cursos o proyectos posteriores.

## Cursos

### Introducción a Python

Curso inicial para aprender los fundamentos de programación usando Python. Se trabaja desde la ejecución de un primer programa hasta la creación de funciones y clases simples, con ejemplos orientados a problemas financieros básicos.

Curso orientado a los conceptos matemáticos necesarios para trabajar con vectores, matrices, sistemas de ecuaciones y transformaciones lineales. Estos contenidos son fundamentales para portafolios, modelos de riesgo, optimización y análisis cuantitativo.

## Estructura del repositorio

Cada módulo tendrá, como mínimo, dos archivos:

- `README.md`: explicación del tema, ejemplos y notas de clase.
- `main.py`: código ejecutable con los mismos ejemplos del README.

Esta estructura permite leer la explicación y luego ejecutar el mismo código para practicar.
