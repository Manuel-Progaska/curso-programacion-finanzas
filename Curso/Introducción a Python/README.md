# Introducción a Python

Este curso introduce los fundamentos de programación con Python desde cero, usando ejemplos simples vinculados al mundo financiero.

La meta no es memorizar sintaxis, sino aprender a pensar en términos de instrucciones, datos, decisiones, repetición y organización del código. Estos elementos serán la base para trabajar luego con análisis de datos, modelos financieros, automatización y librerías como `pandas`, `numpy` o herramientas de visualización.

## Cómo usar este material

Cada módulo tiene dos archivos:

- `README.md`: explicación del tema, ejemplos y ejercicios sugeridos.
- `main.py`: archivo ejecutable con el mismo código del README.

La recomendación para estudiar cada módulo es:

1. Leer la explicación.
2. Revisar el código del README.
3. Ejecutar `main.py`.
4. Modificar valores y observar qué cambia.
5. Resolver los ejercicios sugeridos.
