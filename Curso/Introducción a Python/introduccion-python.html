Introducción a Python

Fundamentos de programación aplicados a finanzas

Propósito del módulo

Este módulo introduce los fundamentos de programación con Python desde cero, usando ejemplos vinculados al mundo financiero.

La meta no es memorizar sintaxis, sino aprender a pensar en términos de:

  • instrucciones;
  • datos;
  • decisiones;
  • repetición;
  • organización del código.

Estos fundamentos serán la base para trabajar con análisis de datos, modelos financieros, automatización y librerías como pandas y numpy.

Cómo usar el material

Cada unidad contiene:

  • un README.md con explicaciones y ejemplos;
  • un main.py con código ejecutable.

Flujo de estudio recomendado:

  1. Leer la explicación.
  2. Revisar el código.
  3. Ejecutar main.py.
  4. Modificar valores y observar los resultados.
  5. Crear ejemplos propios.

Scripts y terminal

Un script es un archivo que contiene instrucciones de Python. Su extensión es .py, por ejemplo, main.py.

El intérprete ejecuta las instrucciones desde la primera línea hasta la última.

# Windows
python main.py

# macOS y Linux
python3 main.py

La terminal permite escribir comandos y ejecutar el intérprete.

¿Qué colección elegir?

  • Lista: importa el orden y los valores pueden cambiar.
  • Tupla: importa el orden y los valores deben permanecer fijos.
  • Diccionario: se necesita asociar una clave con un valor.
  • Conjunto: se necesitan valores únicos y el orden no importa.

Errores comunes con clases

  • Olvidar self en un método.
  • Confundir la clase con un objeto.
  • Usar un atributo no inicializado.
  • Llamar un método sin paréntesis.
  • No respetar la indentación.
